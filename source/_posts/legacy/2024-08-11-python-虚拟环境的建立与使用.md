<li>安装虚拟环境
</li>
<p>``<code> bash
</p>
<p>pip3 install virtualenv
</p>
</code>`<code>
<p>或者
</p>
</code>`<code>bash
<p>python3 -m pip install virtualenv
</p>
</code>`<code>
<li>创建虚拟环境
</li>
</code>`<code>bash
<p>python -m venv path_of_your_venv
</p>
</code>`<code>
<p>或者
</p>
</code>`<code>bash
<p>virtualenv path_of_your_venv
</p>
</code>`<code>
<li>激活虚拟环境
</li>
</code>`<code>bash
<p>source venv/bin/activate
</p>
</code>`<code>
<p>激活后，termninal后显示venv：
</p>
<img src="https://github.com/user-attachments/assets/b91b7d8f-cbc5-4830-a07c-43bd3cd77fd7" alt="image" style="max-width:100%;">
<li>退出虚拟环境
</li>
</code>`<code>bash
<p>deactivate
</p>
</code>``
