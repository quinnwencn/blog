1. 安装虚拟环境
``` bash
pip3 install virtualenv
```
或者
```bash
python3 -m pip install virtualenv
```
2. 创建虚拟环境
```bash
python -m venv path_of_your_venv
```
或者
```bash
virtualenv path_of_your_venv
```
3. 激活虚拟环境
```bash
source venv/bin/activate
```
激活后，termninal后显示venv：
![image](https://github.com/user-attachments/assets/b91b7d8f-cbc5-4830-a07c-43bd3cd77fd7)
4. 退出虚拟环境
```bash
deactivate
```
