在yocto编译中，有时候需要将rootfs中的某个包移除，但是因为有些包是因为被依赖才加入的，因此无法从bb文件中，或者是Image中移除，即通过添加到IMAGE_INSTALL_remove中无法移出，这时候需要找到是哪个包依赖这个包，才能判断是否能移出。
可行的一个方法是：
1. 先生成编译清单：
```bash
bitbake -g <rootfs 镜像> # 例如 bitbake -g xxx-image
```
这一步会生成四个文件：
* pn-buildlist
* package-depends.dot
* task-depends.dot
* pn-depends.dot

2. 从pn-depends.dot中查找
```bash
grep "pkg_name" pn-depends.dot #  例如 grep "python3" pn-depends.dot
```

## 输出文件的作用：
1. pn-buildlist：这个文件列出了构建过程中所涉及到的所有包（PN，Package Name）的列表。它是一个纯文本文件，其中每一行都是一个要构建的包的名称。这个文件可以用来查看构建系统中需要构建的包。
2. package-depends.dot：这是一个以 Graphviz 的 .dot 格式生成的文件，用来描述包（Package）之间的依赖关系。通过这个文件，可以直观地查看每个包依赖于哪些其他包。你可以通过 Graphviz 等工具将其可视化为一个依赖关系图，方便理解整个系统的包依赖结构。
3. task-depends.dot：这个文件以 .dot 格式描述了任务（Task）之间的依赖关系。Yocto 中的每个包构建过程被分成多个任务（如 do_fetch，do_compile，do_install等），这个文件展示了这些任务之间的相互依赖。它对理解整个构建过程中的任务执行顺序有帮助，也可以用 Graphviz 工具进行可视化。
4. pn-depends.dot：这个文件也是 .dot 格式的，它展示了包（Package Name，PN）之间的依赖关系，但与 package-depends.dot不同的是，它仅限于包的名称，而不包括包内的具体版本。它帮助你理解哪些包在构建过程中有相互依赖关系，同样可以用 Graphviz 工具生成依赖图。
