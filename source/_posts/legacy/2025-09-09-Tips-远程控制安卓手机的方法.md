远程控制安卓手机的方法有很多种，一种是使用ToDesk、向日葵等远程工具，但这种方式需要付费，并且需要确保手机在长时间锁屏下不杀死对应后台；另一种免费的方式是通过adb + scrcpy的方式实现windows、mac、linux甚至是iphone控制安卓手机，本文将介绍如何使用scrcpy完成远程控制安卓手机。

# 手机开启USB调试
scrcpy控制手机的底层原理要用到adb，因此必须要将手机的USB调试或者无线调试的开关打开，方法是：
先进入开发者模式：
1. 手机进入设置
2. 找到关于本机
3. 版本信息
4. 多次点击版本号

打开USB调试：
1. 设置
2. 系统与更新
3. 开发者选项
4. 打开USB调试

不同手机会有一些差异，需要根据手机型号和系统来处理。

# adb打开网络调试
电脑安装[scrcpy工具（自带adb）](https://github.com/Genymobile/scrcpy/releases)，将解压后的路径增加到环境变量Path中

<img width="742" height="461" alt="Image" src="https://github.com/user-attachments/assets/50eb227b-fa86-41c3-9035-28f54e4de3a9" />


右键打开命令行，首先通过`adb devices`确认链接手机：

<img width="718" height="86" alt="Image" src="https://github.com/user-attachments/assets/c054a8ea-c0fa-4d3b-acc1-6eab40cbd1aa" />

连接后，如果device显示的是unauthorized，需要在手机端弹窗允许调试。正常查看到手机的UUID和device后，通过以下命令打开网络调试：
```bash
adb tcpip [port num]
# example: adb tcpip 10086
```
验证开启：手机和电脑连接同一网络，然后通过`adb connect`命令测试连接：
```bash
adb connect 192.168.1.99(phone ip):10086
```
连接后直接电脑端运行scrcpy即可控制手机：

# iphone实现远程控制安卓手机
上述例子中电脑控制安卓手机，电脑和手机都处于同一网络内（局域网），这也是adb网络调试的条件，scrcpy实现远程控制手机也必须控制手机和被控手机同处于一个网络。一种可行的方式就是使用tailscale VPN，免费版本可以支持100个设备同处于一个局域网，也解决了手机同处一个网络的问题。
安卓手机和iphone需要使用同一个账号登录，否则两者不处于一个局域网，无法远程控制。

安装tailscale后，还需要就可以通过scrcpy远程控制安卓手机，详细步骤如下：
1. iphone下载`scrcpy remote`（目前需要付费购买）
2. 安卓手机打开无线调试（方法同USB调试）
3. iphone打开`safari`浏览器，输入`scrcpy2://adb`，打开`scrcpy remote`的`advanced mode`
4. 输入ip和adb端口10086，即可连接
